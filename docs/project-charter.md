# Product Charter

ContextLines Quick Ask 帮助个人用户在看已有字幕的视频时快速理解刚才听到的英语短语或俚语。

核心流程是：首次填写个人 Worker 地址与连接口令，点击扩展开始监听，听到不理解的台词后按 `Alt+Q`，视频立即暂停在该时间点；查看全屏右上角解释后，按需手动收藏其中的单词或短语，再用 `×` 或快捷键关闭并继续播放。问答不改变窗口焦点。

词单只保存用户主动选择的英文、中文意思和单词或短语类型，不自动保存整句字幕、页面来源或浏览轨迹。首版不做持续转录、持续上传、侧栏、自动历史、复习计划、登录、OCR 或人物识别。音频仅保存在内存循环缓冲区；用户按快捷键后才从最近约 10 秒中裁出最多约 8 秒有效语音发送。扩展不保存音频或转写。
